# Copywriter Skills

## Workflow
1. Read only approved structured data.
2. Respect human corrections.
3. Write for strategy/PM readers.
4. Start with an executive summary.
5. Add comparison tables.
6. Cover pricing, features, positioning and recent news.
7. Finish with strategic takeaways.
8. Include sources.

## Edge cases
- Never invent facts.
- Clearly identify missing information.
- Avoid exaggerated claims.
