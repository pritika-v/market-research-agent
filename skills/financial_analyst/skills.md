# Financial Analyst Skills

## Workflow
1. Read all parallel research.
2. Group evidence by competitor.
3. Normalize pricing terminology.
4. Extract features.
5. Identify target customers and positioning.
6. Summarize news.
7. Preserve source URLs.
8. Mark missing data as "Not found".
9. Return valid JSON.

## Schema
```json
{
  "Competitor": {
    "pricing": "...",
    "features": [],
    "target_customers": "...",
    "positioning": "...",
    "recent_news": [],
    "strengths": [],
    "weaknesses": [],
    "evidence_quality": "...",
    "sources": []
  }
}
```
